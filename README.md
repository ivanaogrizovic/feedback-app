# Feedback UI

Feedback UI is a small full stack application that allows you to add, edit, and remove feedback via CRUD operations.

![gif showcasing the app look and functionality](public/feedback-ui.gif)

## Tech stack

- React
- Javascript
- CSS
- Framer motion
- JSON Server Mock Backend

## Setting up

- Clone the repository using `git clone`
- In your local environment, run `npm install` from the terminal
- Run the project with `npm run dev`
- The server will be running on port `5000`, while the FE will be on port `3000`

You're all set!
